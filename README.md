# 오늘의 할 일 ✅

매일 할 일을 그리드로 체크하고 달력으로 한눈에 확인하는 PWA 앱입니다.

## 기능
- 3열 그리드 체크리스트
- 개인 항목 추가/삭제 (✏️ 편집 버튼)
- 한 달 달력 보기 (완료 숫자 표시)
- 오늘 현황 / 월간 현황 공유 (카카오톡, 공유, 복사)
- 통계 (연속 달성 등)
- 오프라인 지원 (PWA)

## GitHub Pages 배포 방법

1. 이 저장소를 GitHub에 Push
2. Settings → Pages → Source: `main` 브랜치, `/ (root)` 선택
3. Save → 몇 분 후 `https://유저명.github.io/저장소명` 으로 접속 가능

## 핸드폰 설치 방법

**아이폰 (Safari)**
1. Safari로 접속
2. 하단 공유 버튼 탭
3. "홈 화면에 추가" 선택

**안드로이드 (Chrome)**
1. Chrome으로 접속
2. 주소창 오른쪽 메뉴 탭
3. "홈 화면에 추가" 선택
